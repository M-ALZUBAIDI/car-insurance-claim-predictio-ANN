# models/

This folder holds the trained model and preprocessing artifacts:

- `insurance_risk_model.h5` — Model 5 (class-weighted ANN), the final deployed model
- `scaler.pkl` — fitted `StandardScaler`
- `ordinal_encoder.pkl` — fitted `OrdinalEncoder` for Age/Driving Experience/Education/Income/Vehicle Year
- `feature_columns.pkl` — final feature column order after encoding

These files are generated by running `notebooks/insurance_risk_ann.ipynb` end to end (they're git-ignored due to size). After running the notebook, copy or move the four files here so `src/inference.py` and the upcoming Streamlit app can find them.
